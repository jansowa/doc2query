# ADR: P06-T — świadoma rezygnacja z ręcznego audytu tłumaczeń

Data: 2026-07-26

Status: `ACCEPTED — P06-T WAIVED`

Zakres: frozen train v1; `final_tests_used=[]`

## Kontekst

ADR source provenance zastąpił masowy rescoring P-06 małym ręcznym audytem
P06-T. Próbka 300 rekordów, manifest i ślepy formularz zostały zamrożone, ale
oceny ręczne nie zostały wykonane.

Właściciel projektu świadomie akceptuje resztkowe ryzyko błędów tłumaczenia.
Jako praktyczną przesłankę wskazuje wcześniejsze wytrenowanie na tym zbiorze
wysokiej jakości embeddera retrievalowego. Repozytorium nie zawiera w tej
chwili porównywalnego artefaktu ani metryk tego wcześniejszego treningu, więc
informacja ta jest doświadczeniem właściciela, a nie nowym wynikiem
eksperymentalnym raportowanym przez bieżący program.

## Decyzja

1. Ręczny audyt P06-T zostaje `WAIVED` i nie jest już bramką dla Task 05 ani
   Task 09.
2. Zamrożona próbka i pusty formularz pozostają artefaktem provenance, ale nie
   będą oceniane ani interpretowane jako wynik jakościowy.
3. Frozen train pozostaje bez zmian. Nadal obowiązuje inkluzywny filtr
   `source_en_score >= 23.50`; w bieżącym frozen train nie ma zaakceptowanych
   pozytywów poniżej tej granicy.
4. Nie dodaje się filtra translation-risk, progu lokalnego rerankera ani wag
   `drop/weighted`. Nie wznawia się pełnego `score_train_margins`.
5. Ewentualne jednostkowe błędy tłumaczeń są zaakceptowanym ryzykiem danych.
   Powrót do automatycznej filtracji wymaga nowego prospektywnego ADR i dowodu
   powtarzalnej klasy błędu.
6. Decyzja nie otwiera testów finalnych i nie zastępuje pełnej bramki hard
   negative'ów ani pozostałych zależności kampanii.

## Wpływ na kolejkę

P06-T jest rozstrzygnięte decyzją właściciela, a nie pomiarem. Następną
niezależną bramką pozostaje pełna walidacja polityki hard negative'ów na
zamrożonym dev. Po jej rozstrzygnięciu operacyjna kolejka może przejść do
eksperymentów Task 05 zgodnie z centralnym rejestrem.
